# سازنده‌ی کانفیگ میکروتیک (MikroTik Config Builder)

یک صفحه‌ی وب ساده که بر اساس **مدل دقیق دستگاه** و **نسخه‌ی RouterOS** یک اسکریپت آماده‌ی کانفیگ میکروتیک می‌سازد.

## چرا؟
دستورهای RouterOS بین نسخه‌ها فرق دارند. مثلاً NTP در v6 و v7 فرق می‌کند، و منوی وایرلس در نسخه‌ی 7.13 از `wifiwave2` به `wifi` تغییر کرده است. پورت‌ها و نوع وایرلس هم به مدل دستگاه بستگی دارند. اگر اسکریپتی که برای یک نسخه یا مدل نوشته شده روی دستگاه دیگری اجرا شود، خطای «سطر و ستون» می‌دهد یا نصفه اجرا می‌شود.

## امکانات نسخه‌ی اول
- انتخاب مدل (hAP، hEX، RB4011، RB5009، CCR، CHR، x86 و ...) و نسخه (6.45 تا 7.21)
- WAN: DHCP، PPPoE، IP ثابت، و VLAN (اختیاری)
- LAN: Bridge، سرور DHCP، DNS
- وای‌فای با درایور درست برای هر نسخه (`wireless` / `wifiwave2` / `wifi`)
- فایروال پایه، NAT، بستن سرویس‌های ناامن، تغییر رمز admin
- **بررسی خودکار روی روتر:** اسکریپت اول کار نسخه‌ی RouterOS و وجود پورت‌ها را چک می‌کند و اگر دستگاه یا نسخه اشتباه باشد، قبل از اینکه چیزی را تغییر دهد متوقف می‌شود.

## روش استفاده
فایل `index.html` را در مرورگر باز کنید. نصب هیچ چیزی لازم نیست.

## اجرای تست‌ها
```
node test/generator.test.js
```

## ساختار پروژه
| فایل | کار |
|---|---|
| `index.html` | صفحه‌ی اصلی |
| `css/style.css` | ظاهر صفحه |
| `js/data.js` | فهرست مدل‌ها و نسخه‌ها |
| `js/generator.js` | ساخت اسکریپت RouterOS |
| `js/app.js` | اتصال فرم به سازنده‌ی اسکریپت |
| `test/` | تست‌ها |

> ⚠️ قبل از استفاده روی روتر اصلی، اسکریپت را روی CHR یا یک دستگاه تست امتحان کنید.
